## 3. โพสต์กลุ่ม DPO / HR / กฎหมาย / PDPA (และ LinkedIn)

```
มาตรา 37 ของ PDPA กำหนดให้ผู้ควบคุมข้อมูลมี "มาตรการรักษาความมั่นคงปลอดภัยที่เหมาะสม" แต่วันนี้พนักงานจำนวนมากวางข้อมูลลูกค้าลง ChatGPT, Gemini, Claude ทุกวัน โดยองค์กรยังไม่มีเครื่องมืออะไรกั้นเลย

Thai PDPA Guard เป็นส่วนขยาย Chrome ที่ตรวจจับข้อมูลส่วนบุคคลแบบไทยในกล่องข้อความของเว็บ AI แล้วปิดบังก่อนส่ง
• เลขบัตรประชาชน/เลขผู้เสียภาษี ตรวจด้วย checksum ของกรมการปกครอง ไม่ใช่แค่นับ 13 หลัก
• ที่อยู่แบบ ต./อ./จ. ชื่อพร้อมคำนำหน้า เบอร์โทร เลขบัญชี บัตรเครดิต
• มีโหมดบล็อกการส่งสำหรับองค์กร
• ประมวลผลในเครื่องทั้งหมด ไม่มีเซิร์ฟเวอร์ ไม่มีข้อมูลออกนอกเครื่อง จึงไม่สร้างความเสี่ยงการโอนข้อมูลเพิ่ม
• ขอสิทธิ์แค่ 4 เว็บ (chatgpt.com, chat.openai.com, claude.ai, gemini.google.com)

ใช้ฟรี — ยินดีรับฟังความเห็นจาก DPO และฝ่ายกฎหมายทุกท่าน โดยเฉพาะเคสที่ระบบยังจับไม่ได้หรือจับเกิน
https://pdpa.tm8labs.com/
```

## 5. ตอบคำถามที่จะเจอบ่อย (คัดลอกไปตอบคอมเมนต์)

- **ส่งข้อมูลไปหาคนทำไหม** → ไม่ครับ ไม่มีเซิร์ฟเวอร์เลย ทุกอย่างทำในเบราว์เซอร์ นโยบายอยู่ที่ https://pdpa.tm8labs.com/privacy/
- **AI จะตอบมั่วไหม** → ไม่ครับ ตัวแทนอย่าง [บุคคล_1] บอก AI ว่าตรงนั้นคือชื่อคน มันยังร่างข้อความได้ตามปกติ
- **เตือนผิด** → กด "ข้ามครั้งนี้" หรือเอาติ๊กรายการนั้นออกได้ และแจ้งเคสมาได้เลยจะได้ปรับ
- **ใช้กับ Copilot / Perplexity / มือถือได้ไหม** → ตอนนี้ยังครับ รองรับ ChatGPT, Claude, Gemini บน Chrome คอมพิวเตอร์ก่อน
- **ใช้ทั้งองค์กรได้ไหม** → ได้ครับ ทักมาที่ support@tm8labs.com
